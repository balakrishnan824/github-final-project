# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork this repository.
2. Create a new branch for your change: `git checkout -b my-change`
3. Make your changes and commit them: `git commit -m "Describe your change"`
4. Push the branch to your fork: `git push origin my-change`
5. Open a pull request.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
