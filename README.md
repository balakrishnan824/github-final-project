# Simple Interest Calculator

A simple Bash script that calculates simple interest from user input.

## Formula

```
Simple Interest = (Principal x Rate x Time) / 100
```

- **Principal**: the initial amount of money
- **Rate**: the annual rate of interest (in %)
- **Time**: the time period (in years)

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script asks for three inputs: principal, rate of interest and time period.

## Example

```
Enter principal amount: 1000
Enter rate of interest (%): 5
Enter time period (years): 2
Simple Interest = 100.00
```

## Requirements

- Bash
- `bc` (basic calculator)
